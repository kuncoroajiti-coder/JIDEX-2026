# JIDEX 2026

Jakarta International Design Exhibition 2026.

## Project

JIDEX 2026 is a bilingual event information portal and participant registration platform developed by:

**Unit Penunjang Akademik Desain dan Periklanan**  
**Politeknik Negeri Media Kreatif**

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- Node.js
- PostgreSQL
- Vercel
- Railway
- Cursor

## User Roles

- Public
- Participant
- Operator
- Admin

## Languages

- Bahasa Indonesia
- English

## Development

This project is developed using Cursor, Git, Vercel and Railway.
