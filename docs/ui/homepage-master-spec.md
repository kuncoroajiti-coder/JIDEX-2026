# JIDEX 2026 — Homepage Master UI/UX Specification

## Visual Direction

The homepage must translate the approved JIDEX 2026 visual reference into a
cohesive digital experience.

Core characteristics:

- Elegant
- Editorial
- Contemporary
- International
- Spacious
- Design-led
- Functional

The original JIDEX visual identity is the master reference.

## Layout

### Desktop

- Maximum content width: 1280px
- Header height: approximately 80px
- Hero height: approximately 620–680px
- Hero uses a two-column asymmetric composition
- Text occupies approximately 48%
- Visual occupies approximately 52%
- Generous whitespace is intentional

### Mobile

Mobile uses a dedicated vertical composition:

1. Header
2. Hero typography
3. Hero visual
4. Primary CTA
5. Visual wave transition
6. Countdown
7. About
8. Main programs
9. Program highlights
10. News

## Hero Visual

The hero visual must be integrated into the composition.

Use the approved JIDEX visual assets as visual material, not as an unrelated
image card.

Avoid:

- unnecessary floating badges
- duplicated text
- excessive borders
- artificial decorative elements
- visual elements that appear pasted onto the layout

The exhibition installation, globe, and fashion visual language should feel
like one continuous JIDEX composition.

## Visual Transition

Use a subtle flowing wave between major sections.

Characteristics:

- thin flowing lines
- multicolor accents
- low visual weight
- white/light-blue background
- no hard section divider

## Design Principles

1. The approved JIDEX visual reference is the master visual direction.
2. Do not introduce unrelated visual styles.
3. Do not treat photographs as isolated decorative cards when they belong to
   the overall composition.
4. Preserve generous whitespace.
5. Use color accents deliberately.
6. Keep typography as the primary visual hierarchy.
7. Every repeated UI element must use the shared JIDEX design system.
8. Content such as news and schedules must be data-driven and editable through
   the Operator CMS.
9. Desktop and mobile are both first-class layouts.
10. Functional clarity must never be sacrificed for decoration.
